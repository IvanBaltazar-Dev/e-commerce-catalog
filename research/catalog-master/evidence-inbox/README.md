# Bandeja de evidencia física

Coloca fotos y documentos en la carpeta de la marca correspondiente:

- `01_STRONGER`
- `02_SUN`
- `03_MYSTYLE`
- `04_CANDY_SECRET`
- `05_ROSE_AND_LIN`
- `06_CHARM_LIMIT`

Para cada producto usa, si es posible, nombres como:

- `producto_frente.jpg`
- `producto_reverso.jpg`
- `producto_codigo_o_placa.jpg`
- `producto_caja_o_carta_tonos.jpg`
- `producto_proveedor.txt` o una foto de factura/boleta

No hace falta fotografiar las 152 variantes desde el inicio. Una referencia representativa por familia permite identificar fabricante, catálogo y estructura; luego se amplía únicamente donde siga faltando evidencia.
